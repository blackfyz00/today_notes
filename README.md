# Bright Today 📅
**Bright Today** — это современное Open Source приложение для ведения заметок и дневников, построенное на принципах полной приватности и архитектуры **Local-first**.

Ваши мысли, фото и голос принадлежат только вам. Никаких серверов, никаких подписок, никакого сбора данных.

---

## ✨ Ваши возможности
*   **Markdown:** Полная поддержка разметки для эстетичных и структурированных записей.
*   **Мультимедийный календарь:** Фото и аудио прямо в тексте заметки.
*   **Zero-Backend Architecture:** Приложение работает напрямую с личным Google Drive.
*   **Privacy by Design:** Данные не проходят через наши серверы. Взломать нас невозможно — потому что у нас нет ваших данных.
*   **Кроссплатформенность:** Доступно в Web и на Android.

---

## 🛠 Технический стек
*   **Frontend:** Vue 3 (Composition API) + Vite
*   **Storage:** Google Drive API
*   **Mobile:** Capacitor
